PORTOFOLIO HTML, CSS, JAVASCRIPT

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder uspace_portfolio.
3. Klik dua kali index.html, atau buka folder dengan VS Code dan jalankan memakai Live Server.

CARA KUSTOMISASI
- Nama dan tagline: edit teks di index.html.
- Foto profil: letakkan foto bernama profile.jpg di folder yang sama dengan index.html.
- Perkenalan: edit teks pada section id="biography".
- Link media sosial: ganti atribut href pada tombol Instagram, TikTok, LinkedIn.
- Skill dan persentase: edit teks skill serta nilai --level pada style inline di index.html. Contoh: style="--level:70%".
- Proyek: ganti nama PROJECT ONE/TWO/THREE dan URL href pada section id="projects".
- Warna utama: ubah variabel --gold dan --gold-light di bagian :root pada style.css.
